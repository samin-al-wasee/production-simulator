# Observability Components

Seeing what is happening: metrics, logs, traces, and dashboards. ForgeLab requires **observable by default** — completed components ship observability, never an afterthought.

**Status:** cataloged in `docs/component-catalog.md` — nothing implemented yet.

## Planned components

| Component | Provides | Status |
|---|---|---|
| OpenTelemetry | Instrumentation protocol, collectors, exporters | planned |
| Prometheus | Metrics collection, alert rules | planned |
| Grafana | Dashboards, alerting UI | planned |
| Loki | Log aggregation and search | planned |
| Tempo | Distributed traces | planned |

A component that cannot be observed is not complete.
